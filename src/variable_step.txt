### 整体方案设想

在保持 trainv1_variable3_debug.py 整体架构不变的前提下，建立 bpp → 最优 T* 的映射函数，用码率自适应的时间步替换固定的 T


### 方案细节

步骤一. **确定 $T^*$ (Dynamic Timestep Allocation):**
   通过网络内部对当前通道量化误差的估计（利用 Entropy Model 的 $\sigma$），解析计算当前特征的 $\text{SNR}$，反推出对应的 $T^*$。
   $$ T^* = \text{SNR}^{-1} \left( \frac{\text{Var}(l)}{\sigma_{quant}^2} \right) $$

步骤二. **条件化编解码 (Conditioned Codec):**
   将算出的 $T^*$ 转化为 Time Embedding，注入到 $g_a$ 和 $g_s$ 中。
   $l_{T^*} = g_s(\hat{y}, T_{emb}^*)$


### 实现细节

步骤一. 确定 $T^*$ (Dynamic Timestep Allocation)（两种思路选一种即可）
### 思路一：轻量级的学习映射网络（MLP Mapping）
这是最直接的“端到端学习”方法。
*   **设计：** 在网络中加入一个非常小的 MLP（多层感知机）模块。
*   **输入：** 用户设定的目标码率（或者是控制码率的拉格朗日乘子 $\lambda$），以及当前输入图像提取出的一点全局特征（比如 Global Average Pooling 后的向量）。
*   **输出：** 当前图像在这个目标码率下，最适合的时间步 $T^*$。
### 思路二：基于信噪比的解析计算模块（无需额外参数）
这是更偏数学、更优雅的方案，直接利用现成的熵模型（Entropy Model）数据。
*   **设计：** 不需要额外的可学习网络，写一个直接计算的公式模块。
*   **逻辑：** 压缩网络在量化隐变量 $y$ 时，熵模型会估计出它的方差 $\sigma$。我们直接用隐变量的方差除以量化误差的方差，求出当前压缩的**真实信噪比（SNR）**。
*   **映射：** 因为扩散模型中每个时间步 $t$ 对应的信噪比 $\text{SNR}(t) = \frac{\bar{\alpha}_t}{1-\bar{\alpha}_t}$ 是固定且已知的，模块只需在代码里查表或反解，找到与“压缩信噪比”最接近的时间步，赋值给 $T^*$。

步骤二. 条件化编解码 (Conditioned Codec)

要让编解码器 $g_a$ 和 $g_s$ 理解连续变量 $T^*$，在深度学习中有一个标准且极其优雅的解决方案：**FiLM (Feature-wise Linear Modulation) 配合正弦位置编码**。

由于 StableCodec 的 $g_a$ 和 $g_s$ 是由残差块（InceptionNeXt / GatedCNN）组成的，只需要对这些块进行如下轻量级改造：

#### 第一步：将浮点数 $T^*$ 编码为向量 (Timestep Embedding)
$T^*$ 是一个算出来的连续值（比如 342.7）。
1. 使用经典的 Transformer 正弦/余弦位置编码（Sinusoidal Positional Encoding），将标量 $T^*$ 变成一个高维向量（例如 256 维）。
2. 将这个向量通过一个两层的小 MLP（Multi-Layer Perceptron），提取特征：
   $$ emb_{T} = \text{MLP}(\text{Sinusoidal}(T^*)) $$
   *注：整个网络共享这一个 $emb_{T}$ 向量。*

#### 第二步：改造 $g_a$ 和 $g_s$ 的卷积块（加入 FiLM 层）
原本的 $g_a$ 和 $g_s$ 里的残差块是这样的：
`Input -> Conv -> LayerNorm -> GELU -> Conv -> Output`

现在，利用 $emb_{T}$ 对特征图进行**缩放（Scale, $\gamma$）和偏移（Shift, $\beta$）**：
1. 用一个线性层，从 $emb_{T}$ 预测出两个与特征图通道数相同的向量 $\gamma$ 和 $\beta$：
   `gamma, beta = Linear(emb_T)`
2. 将这两个向量作用在归一化（LayerNorm）之后的特征图上：
   `Feature_new = Feature_old * (1 + gamma) + beta`

#### 第三步：代码层面的伪代码演示（以 PyTorch 为例）

```python
import torch
import torch.nn as nn

class ConditionalBlock(nn.Module):
    def __init__(self, in_channels, time_emb_dim):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, in_channels, 3, padding=1)
        self.norm = nn.LayerNorm(in_channels)
        self.act = nn.GELU()
        self.conv2 = nn.Conv2d(in_channels, in_channels, 3, padding=1)
        
        # FiLM 投影层：将时间 embedding 映射为特征通道的 scale 和 shift
        self.time_mlp = nn.Linear(time_emb_dim, in_channels * 2) 

    def forward(self, x, t_emb):
        # 正常卷积
        residual = x
        x = self.conv1(x)
        x = x.permute(0, 2, 3, 1) # LayerNorm 需要 channel 在最后
        x = self.norm(x)
        x = x.permute(0, 3, 1, 2)
        
        # --- FiLM 操作开始 ---
        # 算出 scale 和 shift，形状调整为 (Batch, Channel, 1, 1) 以支持广播
        time_params = self.time_mlp(t_emb).unsqueeze(-1).unsqueeze(-1)
        gamma, beta = time_params.chunk(2, dim=1) # 拆分成两半
        
        # 注入 T* 条件！
        x = x * (1 + gamma) + beta
        # --- FiLM 操作结束 ---
        
        x = self.act(x)
        x = self.conv2(x)
        return x + residual

# 在前向传播时：
# t_emb = get_time_embedding(T_star)  # 第一步算出的向量
# y = g_a(image, t_emb)               # T* 条件化编码
# l_T = g_s(y_hat, t_emb)             # T* 条件化解码
```
不需要改变 StableCodec $g_a$ 和 $g_s$ 的整体架构，只需要在每个特征提取块中间，插入一个极其轻量的 **FiLM 层**，通过相乘和相加把 $T^*$ 的信息烙印到特征图中。这个操作计算代价几乎为 0，完全不会拖慢 StableCodec 引以为傲的解码速度。
